Padma Testimonial Studio

1. Extract this ZIP.
2. Open index.html in Chrome or Edge. No npm installation is needed.
3. Keep certificate.ttf beside index.html.
4. Fill in the form and optionally upload a logo and three signature images.
5. Click Print / Save PDF. Use A4, Landscape, 100% scale and enable Background graphics.

The application uses HTML, CSS, SVG and JavaScript.
Uploaded images and entered data stay in the current browser page and are cleared when reloaded.
Use VS Code to edit index.html.
